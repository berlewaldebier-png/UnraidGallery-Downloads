# UnraidGallery voor Android

[Download de nieuwste test-APK](https://github.com/berlewaldebier-png/UnraidGallery-Downloads/releases/download/android-test/UnraidGallery.apk)

Open de APK op je Android-telefoon en kies Bijwerken. Verwijder je bestaande installatie niet eerst. Geef je browser zo nodig toestemming om apps te installeren.

Dit is een testversie, geen stable-release. Updates worden voorlopig handmatig geïnstalleerd.

Deze repository bevat alleen downloads. De broncode wordt apart privé beheerd.
